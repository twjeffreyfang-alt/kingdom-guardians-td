## ⌨️ 快捷鍵一覽

| 快捷鍵 | 功能 |
| :---: | :--- |
| **`1` ~ `7`** | 快速選取 7 位守護者（鍊金工、長弓手、寒霜魔女、聖騎士、烈焰魔導、劍豪、擲彈兵） |
| **`S`** | 切換鏟子工具（剷除單位並回收 40% 金幣） |
| **`Space`** | 遊戲暫停 / 繼續 |
| **`ESC`** | 取消當前選取 / 退出鏟子模式 |

## 🚀 本地開發與啟動指南 (Run Locally)

**前置需求：** Node.js (v18+)

1. 安裝套件依賴：
   ```bash
   npm install
   ```
2. 啟動本機開發伺服器：
   ```bash
   npm run dev
   ```
3. 在瀏覽器打開本機網址（預設 `http://localhost:5173`）即可開始遊戲！
